MULTI-DOCUMENT PDF SPLITTING

The system must determine whether each authorised PDF contains:

* one judgment;
* several separate judgments;
* several versions of the same judgment;
* a search-results index followed by documents;
* an editorial report followed by judgment text; or
* incomplete fragments.

For an authorised multi-document PDF:

1. Detect document boundaries.
2. Split the PDF into logical document records.
3. Preserve the original Drive file ID and original page range.
4. Create a separate candidate record for each apparent judgment.
5. Detect when several records represent the same judicial decision.
6. Keep one canonical judgment while preserving source aliases and provenance.
7. Never merge different cases merely because they appear in the same PDF.
8. Never treat a result-list entry as a judgment.

Use multiple boundary signals, including:

* “Document (1)” or “Documents (n)” markers;
* numbered result indexes;
* repeated case titles;
* court names;
* case numbers;
* coram;
* judgment dates;
* judicial author names;
* “JUDGMENT”;
* “GROUNDS OF JUDGMENT”;
* “ALASAN PENGHAKIMAN”;
* official paragraph numbering;
* abrupt page-number resets;
* repeated publisher footers; and
* substantial changes in document structure.

Do not rely on only one heading because the word “judgment” may also occur inside editorial summaries.

PUBLISHER-CONTENT FIREWALL

ZONE 3: CLEAN JUDICIAL TEXT

FACT, SUBMISSION AND FINDING SEPARATION

The report must distinguish:

* an alleged fact;
* an agreed fact;
* a party’s evidence;
* a party’s submission;
* the lower court’s finding;
* the appellate court’s account;
* the appellate court’s own finding; and
* the final operative order.

Never present a party’s allegation as a judicial finding.

Never present a dissenting view as the court’s majority holding.

Never combine different judges’ reasoning into one institutional ratio unless the judgment supports that treatment.

RATIO DECIDENDI CONTROL

For every proposed ratio, store:

* legal issue;
* material facts;
* legal rule;
* application of the rule;
* outcome;
* opinion author;
* supporting paragraphs;
* necessity to the outcome; and
* confidence level.

If the classification is uncertain, label it:

“Proposed ratio requiring editorial confirmation.”

Do not describe every legal statement made by the judge as ratio decidendi.

SUBSEQUENT TREATMENT

Do not declare a judgment:

* followed;
* applied;
* distinguished;
* doubted;
* overruled;
* reversed; or
* still good law

unless that treatment is supported by a later authorised judicial decision in the repository and has been editorially verified.

Where treatment has not been checked, display:

“Subsequent judicial treatment has not yet been independently verified.”
