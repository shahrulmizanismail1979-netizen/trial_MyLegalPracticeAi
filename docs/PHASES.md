# Phases — Judgment Research Platform

The agent implements **only the active phase** and stops after producing the
completion report in `docs/reports/` and updating
`docs/status/current-phase.json`.

| Phase | Name                                                       | Scope                                                                                                                                                                                                                                                                                         |
| ----- | ---------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 00    | Bootstrap                                                  | Persistent docs, module architecture, `research_*` schema, adapter registry, DB-backed job queue skeleton, synthetic fixtures, smoke tests. **No extraction, OCR, segmentation, or AI.**                                                                                                      |
| 01    | Core Architecture, State Machines & Test Harness           | Full entity set; 20-state container machine and 8-state job machine (guarded transitions, atomic audit events); processor contract (versioning, idempotency, checksums, structured failures, provenance); DB-isolated test harness, fixture factory, golden files, browser e2e. See ADR 0002. |
| 02    | Authentication, Roles, Rights & Quarantine                 | 8-role user model; 13-status rights vocabulary with 17-field append-only rights records; single deny-by-default access-decision function (`decideAccess`, golden-pinned); quarantine/search/external-AI/export gates; rights-review workflow with atomic audit. See ADR 0003.                  |
| 03    | Ingestion                                                  | Upload/registration of folders and ZIP archives; checksum duplicate detection; staging to private storage; rights-review queue UI.                                                                                                                                                            |
| 04    | Extraction                                                 | Text extraction from digital documents behind the OCR/extraction adapters; span model; provenance down to character ranges.                                                                                                                                                                   |
| 05    | Segmentation                                               | Case-candidate detection inside containers (zero/one/many per file, splits across files); human review of candidates.                                                                                                                                                                         |
| 06    | Consolidation                                              | Duplicate/version resolution; merge/split as reviewable transformations; validation, human review & cross-file reconstruction. See ADR 0007.                                                                                                                                                  |
| 07    | Publisher-Content Isolation & Verified Judicial Text       | Section classification (6 categories); isolation gate enforced on all full-text paths; completeness checking; verified judgment records. See ADR 0008.                                                                                                                                        |
| 08    | Search & Research UI                                       | Case metadata extraction (13 fields); duplicate/version detection; PostgreSQL FTS search adapter; judgment viewer routes (paragraphs, source-page comparison, annotations, bookmarks). See ADR 0009.                                                                                          |
| 09    | Exact Quotations & Citation Tools                          | Provenance-traced quotation records with byte-level integrity verification; alteration tracking (omissions, insertions); six citation style templates; export gating by role. See ADR 0010.                                                                                                    |
| 10    | AI-Generated Headnotes & Case Analysis                     | Governed AI pipeline (disabled by default); 17-field structured output; evidence-anchored propositions; DRAFT→REVIEWING→APPROVED/REJECTED status machine; publisher-content exclusion from AI input. See ADR 0011.                                                                             |
| 11a   | Authorities & Legislation Extraction                       | Structured authority records from approved AI runs; 14-label treatment vocabulary; legislation-ref extraction; intra-collection citation graph with limitation disclaimer. See ADR 0012.                                                                                                       |
| 11b   | Research Workspace                                         | Per-user folders, saved searches, reading lists, quotation collections, case-comparison tables, authorities tables; cross-user isolation; student/lecturer permission split. See ADR 0013.                                                                                                     |
| 12a   | Audit Event Coverage                                       | Full audit taxonomy (19 event types); `sanitiseForAudit` text-leak guard; instrumentation of access, search, AI, export, deletion, admin, and failed-access paths; admin audit-query route.                                                                                                    |
| 12b   | Permission-Controlled Exports                              | Six export formats (DOCX, PDF, CSV, JSON, Markdown, bibliography); provenance tagging per section; rights-restricted content stub; export history route.                                                                                                                                       |
| 12c   | Retention & Granular Deletion                              | Per-layer deletion (9 layer kinds); deletion manifest with `backupConfirmed: false`; manifest stored in object storage and DB; `RECORD_DELETED` audit events.                                                                                                                                  |
| 12d   | Security Hardening                                         | Dependency audit and SAST scan; CSRF guard; path-traversal guard for storage keys; upload validation hardening; 13-category penetration test suite. See ADR 0014.                                                                                                                             |
| 13    | Stress Corpus & Capacity Report                            | 500-container synthetic corpus generator; 14 measurement dimensions (throughput, memory, latency, retry, concurrent users, backup/restore); capacity envelope report (`stress-report.md`); worker-handoff path for bulk OCR/AI.                                                                |
| 14    | Controlled Pilot                                           | Five-container synthetic pilot corpus; full pipeline end-to-end (ingest → rights → extraction → segmentation → editorial → verification → search); pilot acceptance gate (7 conditions); `pilot-report.md`. See ADR 0015.                                                                     |

Phase boundaries are strict: later-phase functionality must not be smuggled
into an earlier phase. Changes to this table require a decision record in
`docs/decisions/` (Phase 01's redefinition is recorded in
`docs/decisions/0002-phase-01-redefined-core-architecture.md`; Phase 02's in
`docs/decisions/0003-phase-02-auth-roles-rights-quarantine.md`; Phase 07's in
`docs/decisions/0008-phase-07-publisher-content-isolation.md`).
